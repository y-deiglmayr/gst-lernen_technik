Mikrocontroller: Eine LED blinken lassen

Ein Mikrocontroller ist ein kleiner Computer auf einem Chip. Er arbeitet nach dem EVA-Prinzip:

Eingabe (z. B. Taster, Sensor) → Verarbeitung (Programm) → Ausgabe (z. B. LED, Motor)

Das Blink-Programm

void setup() {
  pinMode(13, OUTPUT);      // Pin 13 wird Ausgang
}
void loop() {
  digitalWrite(13, HIGH);  // 5 V: LED an
  delay(1000);              // 1000 ms = 1 s warten
  digitalWrite(13, LOW);   // 0 V: LED aus
  delay(1000);              // 1 s warten
}

setup() läuft einmal beim Start, loop() wird endlos wiederholt.
HIGH bedeutet 5 V am Pin, LOW bedeutet 0 V. delay wartet in Millisekunden: 1000 ms = 1 s.

Die Schaltung

Die LED braucht einen Vorwiderstand (z. B. 220 Ω), sonst wird der Strom zu groß und die LED geht kaputt.
Eine LED lässt Strom nur in eine Richtung durch: Das lange Bein (Anode) zeigt zum Pluspol (Pin 13), das kurze Bein (Kathode) zu GND (0 V).

Merke

  • setup() einmal, loop() immer wieder.
  • HIGH = 5 V = an, LOW = 0 V = aus, delay(1000) = 1 s warten.
  • LED nie ohne Vorwiderstand, langes Bein zu Plus.

Übung 1 · Millisekunden und Sekunden ★ AFB I

Rechne um. Es gilt: 1 s = 1000 ms.

a) 2000 ms = s
b) 0,5 s = ms
c) 250 ms = s
d) 1,5 s = ms

„Milli“ heißt „Tausendstel“: 1 ms ist der tausendste Teil einer Sekunde.

ms → s: durch 1000 teilen. s → ms: mal 1000 nehmen.

a) 2000 ms : 1000 = 2 s   b) 0,5 s · 1000 = 500 ms   c) 250 ms : 1000 = 0,25 s   d) 1,5 s · 1000 = 1500 ms

Übung 2 · Stimmt das? ★ AFB I
„setup() läuft nur einmal, direkt nach dem Einschalten.“

setup() bereitet alles vor, z. B. pinMode, und läuft einmal.
„LOW bedeutet, dass am Pin 5 V anliegen.“

LOW bedeutet 0 V, HIGH bedeutet 5 V.
„delay(3) wartet 3 Sekunden.“

delay rechnet in Millisekunden: delay(3) wartet nur 3 ms. Für 3 s braucht man delay(3000).
„Ein geänderter Code wirkt erst, wenn er auf das Board hochgeladen wurde.“

Der Mikrocontroller führt das Programm aus, das in seinem Speicher liegt. Erst das Hochladen ersetzt es.
„Bei einer LED ist es egal, wie herum man sie einsteckt.“

Eine LED leitet nur in Durchlassrichtung: Anode (langes Bein) zu Plus, Kathode zu GND.
Übung 3 · Wie oft blinkt es? ★★ AFB II

Im Programm stehen delay(250); nach HIGH und delay(250); nach LOW.

a) Dauer eines Durchlaufs von loop(): ms
b) So oft blinkt die LED in einer Minute: -mal

Ein Durchlauf besteht aus „an“ und „aus“: Zähle beide Wartezeiten zusammen. Die Befehle digitalWrite brauchen praktisch keine Zeit.

Eine Minute hat 60 s = 60 000 ms. Wie oft passt ein Durchlauf hinein?

a) 250 ms + 250 ms = 500 ms

b) 60 000 ms : 500 ms = 120, die LED blinkt 120-mal pro Minute.

Übung 6 · Ohne Vorwiderstand? ★★ AFB II

✍ Ben will Zeit sparen und steckt die LED direkt an Pin 13 und GND, ohne Vorwiderstand. Begründe, warum das keine gute Idee ist. Probiere es vorher im Blink-Labor aus.

Musterbegründung: Der Vorwiderstand begrenzt den Strom durch die LED. Ohne ihn wird der Strom viel zu groß. Die LED wird überlastet und kann durchbrennen, auch der Pin des Mikrocontrollers kann beschädigt werden.

Übung 8 · setup() oder loop()? ★★★ AFB III

✍ Tom schreibt alle vier Blink-Befehle (an, warten, aus, warten) in setup() und lässt loop() leer. Begründe, was passiert und wohin die Befehle gehören.

Musterbegründung: setup() läuft nur einmal beim Start. Die LED geht deshalb nur ein einziges Mal an und wieder aus und bleibt danach dunkel. Damit die LED immer wieder blinkt, gehören die Blink-Befehle in loop(), denn loop() wird endlos wiederholt. In setup() bleibt nur pinMode(13, OUTPUT).
